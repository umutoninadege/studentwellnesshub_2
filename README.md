**Student Wellness Hub**


Student Wellness Hub is a Spring Boot web application that helps manage student wellbeing services on campus. 
It provides user authentication (JWT), user profiles, a hierarchical location model (Province → District → Sector → Cell → Village), 
wellness categories, resources and sessions, and appointment booking for sessions.
